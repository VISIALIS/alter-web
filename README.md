# Alter Web

> **Application web Alter** — Identifiez instantanement n'importe quelle adresse EVM depuis votre navigateur.

| # | Interface | Type | Acces |
|---|-----------|------|-------|
| 1 | **alter-mcp** | Serveur MCP (agents IA) | `brew install VISIALIS/alter/alter-mcp` |
| 2 | **alter-cli** | CLI interactif | `brew install VISIALIS/alter/alter-cli` |
| 3 | **Alter Web** | Application web | [alter.visialis.fr](https://alter.visialis.fr/) |
| 4 | **Alter Desktop** | Application bureau (macOS) | `brew install --cask VISIALIS/alter/alter` |
| 5 | **Alter Mobile** | Application mobile (iOS/Android) | [App Store](https://apps.apple.com/app/alter/id6741094925) / [Google Play](https://play.google.com/store/apps/details?id=com.music.music_theory) |

---

## Utilisation

Ouvrez [alter.visialis.fr](https://alter.visialis.fr/) dans votre navigateur :

```
https://alter.visialis.fr/
https://alter.visialis.fr/#/address/0xdAC17F958D2ee523a2206206994597C13D831ec7
```

Collez une adresse EVM pour obtenir sa classification complete : type de contrat, standards detectes, tokens, proxys, et plus.

## Contenu du depot

Ce depot contient la version compilee de l'application web Flutter, deployee automatiquement via GitHub Pages. Le code source se trouve dans le depot principal [phoenix_0](https://github.com/VISIALIS/phoenix_0).
