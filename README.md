# Alter Web

Progressive Web Application for **Alter** — Multi-chain EVM address intelligence.

## Alter Ecosystem

| # | Interface | Type | Access |
|---|-----------|------|--------|
| 1 | **Alter Web** | Web application | [alter.visialis.fr](https://alter.visialis.fr/) |
| 2 | **Alter Desktop** | macOS application | `brew install --cask VISIALIS/alter/alter` |
| 3 | **alter-cli** | Interactive CLI | `brew install VISIALIS/alter/alter-cli` |
| 4 | **alter-mcp** | MCP server (AI agents) | `brew install VISIALIS/alter/alter-mcp` |
| 5 | **Alter Mobile** | Mobile app (iOS/Android) | [App Store](https://apps.apple.com/) / [Google Play](https://play.google.com/store) |

## Access

```bash
# Open in browser
open https://alter.visialis.fr/
```

The web app is deployed automatically via GitHub Pages from this repository.

## Features

- Classify any EVM address across multiple chains (Ethereum, Gnosis, Polygon, etc.)
- Batch classification for multiple addresses
- Portfolio analysis with token detection
- Works offline as an installable PWA
