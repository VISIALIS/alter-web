Ámbito y modo local actual

Alter funciona actualmente en modo local, sin cuenta de usuario, sin endpoint RPC operado por VISIALIS y sin endpoint MCP remoto alojado por VISIALIS. Los análisis, configuraciones y pruebas de propiedad permanecen en el dispositivo, salvo cuando una función solicitada por el usuario requiere una comunicación directa con un servicio tercero descrito a continuación.

En el flujo local estándar, las direcciones EVM consultadas, los parámetros JSON-RPC y las firmas del wallet no se envían a VISIALIS. Alter no conserva claves privadas y nunca solicita al usuario que comunique una frase de recuperación.

Para aspectos contractuales, consulte los Términos y Condiciones de Uso.

Datos tratados directamente por VISIALIS

VISIALIS recibe datos personales únicamente cuando el usuario los comunica voluntariamente, por ejemplo mediante un mensaje al soporte. Estos datos pueden incluir los datos de contacto del remitente, el contenido de la solicitud y los elementos técnicos adjuntos.

Estos datos se utilizan para responder a la solicitud y asegurar o mejorar el servicio. Según el contexto, el tratamiento se basa en la ejecución de la solicitud o en el interés legítimo de VISIALIS en prestar soporte y garantizar la seguridad. Los elementos de soporte se conservan durante el tiempo necesario para tramitar la solicitud y, después, únicamente durante los plazos exigidos por la ley o necesarios para formular, ejercer o defender reclamaciones.

Alojamiento de la aplicación Web

La aplicación Web es un sitio estático alojado por GitHub Pages, un servicio de GitHub, Inc. La carga de la aplicación requiere una conexión con los servidores de GitHub. GitHub indica que registra y conserva la dirección IP de los visitantes de GitHub Pages con fines de seguridad, incluso sin iniciar sesión en una cuenta GitHub. Estos tratamientos se rigen por la Política de Privacidad de GitHub.

El código de la aplicación no envía al servidor de alojamiento las direcciones EVM consultadas, los parámetros RPC ni las pruebas de firma. VISIALIS no opera ningún proxy de aplicación en este trayecto.

Conexiones de red

Alter dirige las solicitudes directamente desde el dispositivo hacia los servicios necesarios para la función solicitada. VISIALIS no intercepta estas comunicaciones. Según las funciones utilizadas, los destinatarios pueden ser:

  • endpoints RPC públicos, privados o autoalojados elegidos o configurados por el usuario;
  • servicios públicos de metadatos de cadenas, incluido ChainList, al buscar o sincronizar una red;
  • API de exploradores compatibles con Etherscan cuando el usuario configura una clave y activa la importación del historial;
  • el wallet o firmante externo elegido cuando el usuario solicita una conexión o una firma;
  • el servidor GitHub Pages de la aplicación para cargar archivos estáticos y comprobar la versión.

Estos terceros reciben necesariamente la dirección IP de conexión y los datos incluidos en la solicitud. Una solicitud RPC o de explorador puede revelar las direcciones EVM consultadas, el método llamado, la red, el identificador técnico de Alter cuando el navegador lo permite y, en el caso de un explorador, la clave API facilitada por el usuario.

El usuario puede sustituir o eliminar los endpoints sugeridos y utilizar sus propios proveedores. VISIALIS no controla las políticas, los plazos de conservación ni los lugares de tratamiento de los proveedores elegidos. Algunos pueden tratar los datos fuera del Espacio Económico Europeo. El usuario debe consultar sus políticas de privacidad antes de utilizarlos.

Datos públicos on-chain y prototipo de atribución

Una dirección, una transacción y los datos inscritos en una blockchain pública pueden vincularse con una persona y permanecer accesibles durante un largo periodo. VISIALIS no puede modificar ni suprimir los datos ya inscritos en una blockchain.

Las herramientas CLI y MCP que exponen el prototipo transaction.prepare pueden añadir a un payload no firmado un marcador público de atribución en formato ERC-8021, propuesta que todavía se encuentra en fase de borrador. Alter no publica por sí mismo este marcador. Solo se hace público si el usuario hace firmar el payload por un firmante externo y después difunde la transacción. La aplicación Web no ofrece actualmente ningún flujo para preparar o publicar este marcador.

Almacenamiento local y rastreadores

Alter utiliza el almacenamiento del dispositivo para proporcionar las funciones solicitadas y recordar, en particular, el idioma, el estado del onboarding, los avisos descartados, los ajustes y endpoints RPC, los contadores técnicos, el estado de importación del historial y, si el usuario la introduce, una clave API de explorador. Los datos de sesión, direcciones, resultados o pruebas también pueden permanecer localmente según la interfaz utilizada.

La clave API del explorador se almacena localmente sin cifrado y solo se envía a la API del explorador cuando se utiliza la función correspondiente. El usuario debe utilizar una clave específica y puede eliminarla desde los ajustes.

El código de Alter no deposita cookies publicitarias y no incluye herramientas de analítica ni de seguimiento del comportamiento. El almacenamiento local funcional se utiliza para prestar las funciones solicitadas. El usuario puede borrarlo desde la aplicación cuando exista un control, o desde los ajustes del navegador o del sistema; esta eliminación puede reiniciar la aplicación.

Seguridad

VISIALIS recomienda utilizar únicamente endpoints RPC, exploradores y wallets de confianza, no introducir nunca una clave privada o frase de recuperación en Alter y verificar los datos mostrados por el wallet antes de firmar. En caso de duda sobre un servicio tercero, el usuario debe eliminarlo de su configuración.

Derechos de las personas

Respecto de los datos que VISIALIS posee efectivamente, incluidas las solicitudes de soporte, las personas pueden solicitar el acceso, rectificación, supresión, limitación u oposición cuando estos derechos sean aplicables, escribiendo a contact@visialis.fr. También pueden presentar una reclamación ante la autoridad francesa de protección de datos, la CNIL.

Los datos almacenados únicamente en el dispositivo están bajo el control del usuario. Las solicitudes relativas a los registros de GitHub Pages, un proveedor RPC, un explorador o un wallet deben dirigirse al tercero correspondiente. La eliminación local no puede suprimir datos ya publicados en una blockchain.

Evolución del servicio y de la política

Esta política se actualiza cuando cambian los tratamientos o el marco legal. Si VISIALIS introduce un endpoint RPC, un endpoint MCP remoto, una cuenta, una función de pago u otro modo alojado, los nuevos tratamientos, bases jurídicas, plazos de conservación, destinatarios y derechos se documentarán antes de su activación y se comunicarán a los usuarios.
