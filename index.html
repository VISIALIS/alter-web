Alter Web

Classification instantanee d'adresses EVM. Cette page charge l'application Flutter; en attendant, voici les points d'entree utiles.

Quick Start
Web: https://app.alter-evm.com/
CLI: brew install VISIALIS/alter/alter-cli
MCP: brew install VISIALIS/alter/alter-mcp
# Interface Type Installation / Acces
1 Alter Web Application web https://app.alter-evm.com/
2 alter-cli CLI interactif brew install VISIALIS/alter/alter-cli
3 alter-mcp Serveur MCP (agents IA) brew install VISIALIS/alter/alter-mcp
4 Alter Desktop Application desktop (macOS/Windows/Linux) brew install --cask VISIALIS/alter/alter
5 Alter Mobile Application mobile (iOS/Android) App Store / Google Play
