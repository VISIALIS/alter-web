General Principles

  • Alter does not collect, store or transmit any personally identifiable data.
  • The application relies exclusively on public data available through EVM-compatible RPC endpoints.
  • No account, identifier or subscription is required. When a user connects a wallet and signs to prove ownership of an EVM address, the cryptographic proof is stored locally on the device and never sent to VISIALIS or any third party.

For contractual obligations, please review the Terms of Use.

Network Connections

Outbound traffic is limited to public RPC endpoints configured by default or added by the user. VISIALIS does not operate proprietary servers to intercept or enrich these requests. Should VISIALIS offer its own RPC endpoint in the future, this will be clearly indicated in the application and documentation.

RPC requests transmit the user’s IP address and the blockchain addresses queried to the configured RPC node. VISIALIS does not control these third-party nodes and recommends using only trusted endpoints. The user freely chooses and configures their RPC endpoints — Alter does not impose any.

The web version of Alter is delivered as a static application: all interactions remain within the user’s browser. No data related to the addresses viewed or wallet signatures is sent back to the hosting server.

On-chain Attribution Marker (ERC-8021)

Every transaction prepared by Alter contains a public attribution marker (ERC-8021 format), visible on the blockchain to anyone. This marker identifies Alter as the preparation tool — it does not reveal the user’s identity and is not signed by Alter.

If the user activates a premium licence (NFT), Alter reads the licence status directly from the blockchain via a read-only RPC call. No licence data is transmitted to VISIALIS.

Cookies and Local Storage

The web version may store technical preferences locally (such as the status of an information banner). These data stay on the user’s device and are never transmitted to VISIALIS.

Security

VISIALIS recommends using trusted RPC endpoints only. If there is any doubt about a third-party endpoint, users should remove it from the configuration.

User Rights

As no personal data is collected, there is no data enabling rights of access, rectification or erasure. For any question, please contact: contact@visialis.fr.

Changes

This policy may be updated to reflect service or legal developments.

Alter currently operates exclusively in local mode. If a hosted mode is introduced in the future, a dedicated privacy policy will be published and the user will be explicitly informed before any activation.
